# Call of Dragons — калькулятор «Вершины власти»

Обновлённая версия калькулятора с двумя режимами: **«Цель по мощи»** и **«Количество войск»**.

## Что изменено

### Заготовка
- Список заготовок оставлен в нужном порядке:
  - Без заготовки
  - Тренировка T5 (+20 000)
  - Тренировка T5 (+10 000)
  - Тренировка T4 (+20 000)
  - Тренировка T4 (+10 000)
  - Перетренировка T4 → T5 (+20 000)
  - Перетренировка T4 → T5 (+10 000)
- Показывается количество войск по 5 типам, общая мощь заготовки и мощь, которая засчитывается в день события.
- Добавлено поле даты/времени начала события с нативным календарём браузера.
- Можно применить введённую дату вручную или вернуть дату ближайшей «Вершины власти».
- После выбора даты калькулятор автоматически показывает, **когда нужно начать тренировку заготовки**, чтобы она была готова к началу события.
- «Отдельные бонусы для заготовки» открываются во всплывающем окне и не меняют бонусы основного расчёта.

### Режим «Цель по мощи»
- Кнопки типов войск имеют единый вид.
- Активный тип подсвечивается так же, как кнопка «Все типы».
- Нижние поля ручного ввода количества войск убраны: в этом режиме распределение выполняется калькулятором автоматически.
- Основная перетренировка остаётся T4 → T5.

### Режим «Количество войск»
- Все 5 типов войск доступны сразу — отдельные кнопки добавления/удаления типов скрыты.
- Для каждого типа есть отдельное поле количества.
- Перетренировка явно обозначена как **T4 → T5**.
- Для тренировки можно выбрать:
  - общий тир для всех типов;
  - персональный тир для каждого типа.
- Ввод количества работает как обычное числовое поле: можно сразу вводить целое число, включая несколько цифр.
- В результатах отдельной строкой показывается заготовка, если она выбрана.

### Убраны из интерфейса
- Верхняя навигация AKAME.
- Ссылка «На главную».
- Нижний рекламно-информационный блок сайта.

## Файлы
- `index.html` — входная страница.
- `calculators/power-peak.html` — калькулятор.
- `styles.css` — общие стили.

Калькулятор можно открыть локально через `calculators/power-peak.html` или разместить на GitHub Pages.
