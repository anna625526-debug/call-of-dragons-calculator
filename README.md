# Call of Dragons — калькулятор «Вершины власти»

Это версия исходного калькулятора из переданного HTML-файла с добавленным режимом **«Количество войск»**.

## Что сохранено из исходника

- исходная логика режима «Цель по мощи»;
- таблицы стоимости ресурсов из исходного кода;
- тиры, мощь, базовое время;
- бонусы скорости, VIP и камень маны;
- заготовка;
- перетренировка;
- дополнительный вариант перетренировки;
- распознавание T4 по скриншоту;
- сохранение настроек в браузере;
- исходная структура разделов.

## Что добавлено

### Режим «Количество войск»

Если вместо цели по мощи выбран этот режим:

- в разделе «Перетренировка» общий ввод количества скрывается;
- после выбора типов войск появляются отдельные поля для количества T4 → T5;
- в разделе «Тренировка» после выбора типов появляются отдельные поля количества;
- можно выбрать несколько типов и задать каждому своё количество;
- калькулятор считает мощь, ресурсы и ускорения по фактически введённым числам;
- исходный режим «Цель по мощи» при переключении обратно продолжает работать отдельно.

## Структура

- `index.html` — входная страница;
- `calculators/power-peak.html` — сам калькулятор;
- `styles.css` — локальные переменные и базовые стили, необходимые странице;
- `assets/calc/` — папка для иконок ресурсов, если позже захочешь добавить их в репозиторий.

## Запуск на компьютере

Можно просто открыть `calculators/power-peak.html` в браузере.

Для GitHub Pages:

1. Создай репозиторий на GitHub.
2. Загрузи содержимое этой папки целиком.
3. Открой **Settings → Pages**.
4. В **Build and deployment** выбери:
   - **Source:** Deploy from a branch
   - **Branch:** `main`
   - **Folder:** `/ (root)`
5. Нажми **Save**.
6. GitHub выдаст адрес сайта.

После этого калькулятор будет доступен по адресу:

`https://ТВОЙ-ЛОГИН.github.io/НАЗВАНИЕ-РЕПОЗИТОРИЯ/`

## Важно

Файл `power-peak.html` намеренно оставлен самостоятельным HTML-файлом, чтобы исходный код не пришлось переписывать с нуля. Дальнейший дизайн можно менять отдельно, не меняя математическую часть.
